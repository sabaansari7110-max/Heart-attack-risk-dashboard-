
## Project Overview
This project analyzes heart attack risk factors using a dataset of **3,000 patients**. The interactive dashboard highlights key medical, lifestyle, and demographic risk indicators.

**Tools Used**:

- **Excel** — Data cleaning, validation, pivot tables
- 
- **Tableau** — Dashboard design and advanced visualizations
- Data visualization best practices (bar charts, pie charts, histograms)

## Key Insights
- **Total Patients**: 3,000
- **Average Age**: 55.14 years
- **Sex Distribution**: 50.73% Female | 49.27% Male
- 
- **High Risk Patients**: 12.00%

**Major Risk Factors**:
- Smoking: 1,487
- Diabetes: 1,530
- Hypertension: 751
- Alcohol: 785

## Project Features
- Comprehensive data cleaning and validation in Excel
- Interactive Tableau dashboard with multiple filters
- Visual analysis of chest pain types/severity, cholesterol, blood pressure, max heart rate, age distribution, etc.

## Technologies & Skills Demonstrated
- Excel: Data cleaning, validation rules, pivot tables, conditional formatting
- Tableau: Calculated fields, parameters, dashboard actions, layout design
- Data Visualization principles
